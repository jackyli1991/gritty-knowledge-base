
## install


```Zsh
npm install -g @anthropic-ai/claude-code
brew install claude-code

claude --version

cd ~/.claude/settings.json # 配置文件
```


## **Claude Code Router**

```zsh
npm install -g @musistudio/claude-code-router

ccr ui
ccr start # 启动路由服务（后台常驻）
ccr code # 启动 Claude Code 客户端（自动连接本地代理）
```
